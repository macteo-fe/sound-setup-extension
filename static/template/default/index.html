Setup SFX list SFX folder → sound node sfxList

Scans every .mp3 AudioClip in SFX folder and appends new entries to Sound node → sfxList (CustomAudioClipModule: soundId + audioFile). Skips items that already exist (same soundId or same clip). Saves the scene when done.

Fields used:

  • Game ID — strips the {gameId}_ prefix from filenames to build soundId (e.g. 9766_sfx_winline.mp3 → SFX_WINLINE)
  • Sound node — node with SoundPlayerModuleImpl / SlotSoundPlayerModule*; writes sfxList
  • SFX folder — source folder of mp3 clips to add

Not used: Project path, Preserve BGM checkbox.

Generate SoundConfig sound node → SoundConfig{gameId}.ts

Syncs scripts/DataConfig/SoundConfig{gameId}.ts with Sound node lists: sfxList → SOUND_CONFIG (adds new ids, removes ids no longer on scene), musicList → BGM_CONFIG when non-empty. Refreshes the asset in the database.

Fields used:

  • Game ID — output file name SoundConfig{gameId}.ts
  • Project path — game assets root (e.g. cc-release-slot/cc30-nine-tailed-fox-9766)
  • Sound node — reads sfxList → SOUND_CONFIG; musicList → BGM_CONFIG
  • Preserve BGM checkbox — if musicList is empty, keeps existing BGM_CONFIG block from the file on disk

Not used: SFX folder (run Setup SFX list first to populate the node).

Check usage sound node → scan scripts by sound id

Loads soundId values from Sound node → sfxList and musicList, then scans all .ts files under {project}/scripts for references to each sound id (quoted strings, dynamic templates, and optionally SOUND_CONFIG.* / BGM_CONFIG.* when the config file exists). Sounds serialized on the open scene also count as used.

Fields used:

  • Game ID — locates scripts folder and optional SoundConfig{gameId}.ts
  • Project path — scripts folder to search for usages
  • Sound node — source list of sound ids to check

Not used: SFX folder, Preserve BGM checkbox. SoundConfig file is optional.
